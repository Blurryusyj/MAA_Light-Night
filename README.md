# MAA_GY

MAA_GY 是一个基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 制作的《光与夜之恋》日常任务自动化项目，目标是通过勾选任务完成日常流程，减少重复操作。

> 本项目不是游戏官方工具，与游戏官方无关。请自行判断使用风险，并遵守游戏的相关规定。

## 当前功能

目前项目主要包含以下自动化任务：

- 启动游戏及常见登录、公告、奖励弹窗处理
- 信使巡游
- 研习之旅
- 使用灵感道具
- 星座研究
- 星光展馆
- 商城月卡奖励及指定商品兑换
- 战斗关卡扫荡
- 计划奖励一键领取

## 战斗功能说明

当前战斗功能仅针对月卡用户的扫荡流程制作，并不支持任意选择关卡。

- **初心＋极光＋铭迹**：按预设顺序执行月卡扫荡。
- **光影长河＋外婆小铺**：目前只支持游戏内已经选好的固定角色与固定关卡；程序不会自动选择或切换角色、关卡。

未来计划增加关卡、角色等可选项，让战斗流程可以根据用户设置执行。

## 布局限制

当前识别坐标仅适配以下游戏主页布局组合：

- **纪念墙**
- **聆心相伴**

使用其他主页布局时，按钮位置和识别区域可能不同，任务可能无法正常运行。开始使用前，请先将游戏布局调整为上述组合。

## 稳定性说明

本项目目前仍处于早期阶段，其中相当一部分内容是在边学习、边测试的半 Vibe Coding 过程中完成的，因此不能保证所有设备和所有游戏状态下都能稳定运行。

可能遇到的问题包括：

- OCR 偶尔识别失败
- 网络或动画加载时间不同导致步骤超时
- 弹窗、活动页面或游戏更新改变原有流程
- 模拟器分辨率、主页布局不同导致点击位置偏移
- MuMu 重启后 ADB 地址变化或暂未连接

建议第一次使用时在旁观察，不要在无人看管的情况下长时间运行。若任务出错，请停止任务并保留 `debug` 日志，方便定位问题。

## 运行环境

- MuMu 模拟器 12
- 竖屏坐标基准：`736 × 1308`
- MaaFramework / MXU

如果 MuMu 重启后无法连接，可运行项目中的 `sync_mumu_adb.cmd`，自动查询当前端口并同步 ADB 配置。

## 反馈

如果遇到问题，请尽量提供：

1. 出错任务名称
2. 出错前停留的游戏页面
3. MXU 显示的错误信息
4. 对应时间段的 `debug` 日志

这些信息可以显著提高问题定位效率。
